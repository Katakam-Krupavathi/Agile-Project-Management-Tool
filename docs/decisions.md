# Design Decisions & Tradeoffs

| Decision | Choice Made | Alternatives Considered | Rationale & Tradeoff |
| --- | --- | --- | --- |
| **Database** | SQLite in WAL mode with `foreign_keys=ON` and `busy_timeout=5000` | PostgreSQL | Zero operational overhead and instant local/Docker boot for a 3–10 person team. **Tradeoff:** Single-writer concurrency ceiling; migrating to PostgreSQL is straightforward via SQLAlchemy 2 + Alembic. |
| **Async Job Queue** | Durable SQLite `jobs` table + standalone Python worker | Redis + Celery / RQ | Eliminates an extra broker container and provides **transactional outbox** semantics (jobs commit atomically with the domain mutation). **Tradeoff:** Polling latency (~1s) and single-DB write contention under high throughput. |
| **Authentication** | Signed `httpOnly` `SameSite=Lax` cookie + double-submit `X-CSRF-Token` | Bearer JWT in `localStorage` | Protects session tokens from XSS theft (`httpOnly`) while defending against CSRF on all state-changing routes. **Tradeoff:** Requires explicit CSRF header handling and `credentials: 'include'`. |
| **Authorization Leakage** | Non-members receive `404 Not Found` | `403 Forbidden` for non-members | Prevents project/story/task UUID enumeration by unauthorized authenticated users. **Tradeoff:** Slightly less explicit debugging for users accidentally pasting an unshared URL. |
| **Drag-and-Drop Ordering** | Fractional float ranking (`RANK_STEP=1024`) with gap-threshold rebalancing (`MIN_GAP=1e-6`) | Contiguous integer `position` reindexed on every move | Most moves update a single row in O(1); rebalancing only runs when repeated midpoint splits exhaust precision. **Tradeoff:** Extra rebalance branch to test and maintain. |
| **Concurrency Control** | Explicit integer `version` required on `PATCH` (`409 Conflict` on mismatch) | Last-write-wins | Prevents silent overwrites when two teammates edit the same story or task simultaneously, paired with a UI `Reload` toast. **Tradeoff:** Clients must carry and send `version` on every edit. |
| **Live Updates** | Server-Sent Events (SSE) with `Last-Event-ID` | WebSockets / short polling | Native browser `EventSource`, works over standard HTTP/1.1 + Nginx proxy, reconnect-safe, unidirectional server-to-client fit for notifications. **Tradeoff:** One-way only; mutations stay REST. |
| **Rollups & Health** | Pure Python functions in `services/rollup.py` computed over constant-query `/tree` fetch | Denormalized rollup columns updated by triggers | Zero drift between tasks and story progress, trivial to unit test without a DB, and `/tree` executes O(1) queries (guarded by an N+1 test). **Tradeoff:** Recomputes in memory per `/tree` read (negligible for 3–10 user projects). |
